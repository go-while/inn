=head1 NAME

inn - Overview of the InterNetNews documentation

=head1 DESCRIPTION

InterNetNews (INN) is a complete Usenet system.  It includes innd(8), a
server that receives and relays news articles, nnrpd(8), a server that
lets clients read and post articles, and many programs to feed, store,
expire and maintain news.

This man page is an index of the documentation of INN.  It lists all the
man pages installed with INN, by section, and the other documentation
files.

If you are new to INN, start with the F<INSTALL> file.  Then read
inn.conf(5), newsfeeds(5), incoming.conf(5), storage.conf(5),
readers.conf(5) and expire.ctl(5), which are the main configuration
files.  ctlinnd(8) and rc.news(8) explain how to control the running
server, and news.daily(8) the daily maintenance.

The man pages are installed in I<pathnews>/share/man by default.  If they
are not found by B<man>, add this directory to your MANPATH environment
variable or use a command like:

    man -M <pathnews in inn.conf>/share/man inn.conf
