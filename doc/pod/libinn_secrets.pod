=head1 NAME

secrets_read, secrets_free, secrets_print_value, secrets_dump - read the INN secrets configuration

=head1 SYNOPSIS

    #include <inn/secrets.h>

    extern struct secrets *secrets;

    bool secrets_read(const char *path);
    void secrets_free(struct secrets *config);
    bool secrets_print_value(FILE *file, const char *key,
                             enum confparse_quoting quoting);
    void secrets_dump(FILE *file, enum confparse_quoting quoting);

=head1 DESCRIPTION

Call B<innconf_read> successfully before B<secrets_read>, which uses
I<pathetc> to find F<inn-secrets.conf> if I<path> is NULL.  A non-NULL
I<path> selects an alternate file.  The function replaces the global
C<secrets> structure with the administrator and user Cancel-Lock lists
from the first C<cancels> group.  It returns true when the file was
parsed.  It initializes empty lists on read or parse failure.

B<secrets_free> erases the stored secret strings and releases I<config>
and its allocations.  Clear the global pointer if it refers to the
released structure.

B<secrets_print_value> writes the named I<key> from the current
configuration to I<file> using I<quoting> as described in
libinn_confparse(3).  The return value is true for a recognized key.
B<secrets_dump> writes all recognized settings in that representation.
Both routines write secret values, so use a destination with access
controls appropriate for F<inn-secrets.conf>.

=head1 HISTORY

The F<inn-secrets.conf> interface was added with Cancel-Lock support in
2022.
